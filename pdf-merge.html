How to Merge PDF Files

  1. Upload PDFs — Drag two or more PDF files onto the drop zone, or click to browse. You can add files multiple times to arrange them in the right order.
  2. Reorder pages — Drag file cards up or down to set the merge order. Use the ✕ button to remove a file.
  3. Merge & download — Click Merge. A new PDF combining all pages in your chosen order will be ready in seconds.

Why Use a Browser-Based PDF Merger?

Online PDF tools that ask you to upload files pose a privacy risk — your documents could be stored or analyzed on someone else's server. GameImage.tools merges PDFs entirely in your browser using pdf-lib. Your files never leave your device.

When Merging Is the Wrong Tool

Merging is for combining documents that belong together: a contract plus its signed addendum, scanned chapters of one report, or multiple invoices for the same client. If you actually need to remove pages, reorder pages within a single file, or extract one section, use a PDF splitter or page organiser instead — merging first and trimming later produces a bloated file with duplicate pages.

If the goal is to shrink a PDF for email, merging will only make it larger. Compress the individual files first, then merge the smaller versions.

What to Check After Merging

  • Page count — the merged file should equal the sum of all inputs. If it is lower, a file failed to load and was silently skipped.
  • Bookmarks and links — internal links keep working, but some interactive forms lose their field mappings when pages from different documents are combined.
  • Page order — scroll through the first and last pages of each section, since drag-and-drop order is easy to get wrong with many files.
  • File size — a merged PDF is roughly the sum of its parts, with no re-compression applied.

Frequently Asked Questions

Can I merge PDFs with different page sizes?

Yes — each page keeps its original size in the merged document.

Why does some PDF show an error when uploading?

Some PDFs use newer internal structures or have permission protection that browser tools cannot parse. Open the PDF in your reader, save a fresh copy, then upload again.

Is there a file size limit?

Each PDF can be up to 50MB, and you can merge up to 10 files at a time. All processing happens locally so there's no network bottleneck.

Does merging reduce quality or remove text?

No. Merging copies page content as-is, so text stays selectable and images keep their original resolution. Nothing is re-rendered or re-compressed.

Can I merge password-protected PDFs?

If a PDF only has an owner password (restrictions on printing or editing), it usually merges fine. If opening the file requires a password, remove the password first — browsers cannot prompt for it during the merge.
