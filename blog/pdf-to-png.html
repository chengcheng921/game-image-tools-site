PDF to PNG: Convert Every Page to a Sharp Image

Published on Nov 16, 2026 · 5 min read

Open the PDF to image converter, drop in the document, set the output to PNG, and every page is rendered as a separate image you can download individually or as a set. The conversion happens in the browser, so confidential documents never travel to a server. The decision that actually matters is PNG versus JPG, and that depends on what the page contains — text and diagrams behave very differently from scanned photographs.

PNG or JPG for a PDF Page?

Page contentBest formatReason
Text, tables, contracts, invoicesPNGLossless edges, readable small type
Diagrams, charts, UI mockupsPNGFlat colour and hard lines survive
Scanned photos, magazine spreadsJPGContinuous tone, far smaller file
Mixed report with photos and textPNG if under ~10 MB, else JPGBalance of sharpness and size
Slides exported from a deckPNGLarge flat areas and crisp captions

The rule of thumb: if the page is mostly white space with dark pixels on top, PNG will look cleaner. If it is a photograph or a scan with continuous gradients, PNG will be several times larger for no visible gain, and JPG is the pragmatic choice.

What Resolution You Actually Get

A PDF does not contain pixels — it contains drawing instructions measured in points, where one point is 1/72 inch. Rendering turns those instructions into a pixel grid, and the size of that grid determines sharpness. This converter renders each page at twice its point size, so a US Letter page of 612 × 792 points becomes 1224 × 1584 pixels. That works out to roughly 144 DPI.

For screen use — pasting a page into a document, sharing a form, attaching an image to a support ticket — 144 DPI is comfortably sharp. For professional printing, commercial print shops usually ask for 300 DPI, which would need a 2550 × 3300 pixel render and a different tool. Being honest about this limit saves you a rejected print job.

Why Text-Only Pages Need PNG

JPG divides the image into 8 × 8 blocks and approximates each one. On photographic content the approximation is invisible. On a page of 10-point text, every block boundary sits next to a glyph, and the approximation shows up as grey fringing and blocky stair-steps around letters. Thin table rules can even disappear at moderate quality settings.

PNG stores exact pixel values, so a 1-pixel border stays a clean 1-pixel border and small text stays legible when someone zooms in. That is why screenshots, diagrams and documents are almost always stored as PNG, while camera images are stored as JPG.

Converting a Document Step by Step

  1. Trim the document if you only need part of it. The PDF splitter extracts a page range into a smaller file, which makes the conversion faster and keeps the output folder manageable.
  2. Drop the PDF into the converter. The PDF to image tool reads the file, parses the page tree and shows how many pages it found.
  3. Pick PNG as the output format. Switching to JPG later is one click, so there is no harm in converting one page each way and comparing when you are unsure.
  4. Download individually or all at once. Each page gets its own file, named by page number, so the order stays clear even if the export lands in a folder full of other images.

When a PNG Page Becomes Too Large

A 1224 × 1584 PNG of a dense page can land anywhere from 200 KB to 4 MB depending on how much detail and photography it contains. Exporting a fifty-page report as PNG can therefore produce a few hundred megabytes. Two practical fixes:

  • Convert only the pages you need by splitting first, rather than exporting the whole document.
  • Compress the PNG afterwards with the image compressor, which reduces the colour palette. This works well on text pages, which typically use very few distinct colours, and barely helps on scans.

Common Uses for Page Images

A few situations come up repeatedly. Designers export a slide as PNG to drop into a mockup without linking the original deck. Support teams convert a page of an invoice to PNG so it can be pasted into a chat. Bloggers convert a single page of a whitepaper into an image because the hosting platform will not accept a PDF. Students export a page of lecture notes to annotate on a tablet. In all four cases the source is text-heavy, which is exactly where PNG wins.

Frequently Asked Questions

How do I convert a PDF to PNG?

Open the PDF to image converter, drop the PDF in, set the output format to PNG, and each page is rendered as a separate image. Download pages individually or save the whole set in one go. The file stays in your browser and is never uploaded.

What resolution does a PDF page become?

Each page is rendered at twice its point size. A US Letter page of 612 by 792 points becomes 1224 by 1584 pixels, which is roughly 144 DPI. That is sharp on screen and acceptable for most print-at-home uses, but it is not a 300 DPI print master.

Why does PNG look better than JPG for PDF text?

JPG compression works in blocks and smears colour around edges, which shows up as fuzzy halos around small text and thin lines. PNG is lossless, so glyph edges and one-pixel table borders stay exactly where the renderer put them.

Can I convert only one page of a PDF?

Use the PDF splitter first to cut the document down to the pages you need, then convert that smaller file. Converting a 200-page report to get page 7 wastes both time and disk space.

Is the PNG background transparent?

No. A PDF page has no inherent transparency, so the rendered PNG is filled with the page background, which is white in almost every document. If you need a transparent cut-out, place the PNG in an editor and remove the background there.
