How to Split a PDF

  1. Upload a PDF — Drag the file onto the drop zone or click to browse. The tool shows the total page count immediately.
  2. Enter a page range — Type the start and end page for the part you want to extract (pages start at 1).
  3. Add more ranges if needed — Click "+ Add Range" to extract several sections in one go, e.g. pages 1–5 and 20–25.
  4. Split & download — One range downloads as a single PDF; multiple ranges are packaged into a ZIP file.

Extract Exactly the Pages You Need

Big PDFs are rarely useful end to end. You want one raid-guide chapter from a 200-page manual, a single signed page from a contract, or just the character sheet appendix from a rulebook. Uploading those documents to a random server is a privacy gamble — especially contracts and IDs. This splitter copies pages locally in your browser using pdf-lib, so the content never leaves your device, there's no queue, and it's free with no watermarks or page limits.

How Page Ranges Work

Each range you add becomes its own output PDF, named with its page span (e.g. guide_3-7.pdf). Ranges can overlap and can be in any order. When you request more than one range, the results are zipped together — browsers block a single click from triggering many separate downloads.

Frequently Asked Questions

Does splitting reduce PDF quality?

No — pages are copied as-is into the new files. Text stays selectable, images keep their original resolution, and nothing is re-compressed.

Why do I get a ZIP instead of separate PDFs?

Browsers block one click from starting multiple downloads, so when you split into several ranges they're bundled into a single ZIP for convenience.

My PDF fails to load — why?

Password-protected or unusually structured PDFs can't be parsed in the browser. Open the file in your PDF reader, print/save it as a fresh unprotected PDF, then try again.
