How to Use the Image Resizer

  1. Upload — Drag a screenshot onto the drop zone or click to browse. PNG, JPG, and WebP files up to 20MB are supported.
  2. Set exact pixels — Type a width or height. With "Keep aspect ratio" checked (the default), the other dimension updates automatically so nothing gets stretched.
  3. Or pick a platform preset — The preset menu already knows the official dimensions: Steam capsules (920×430, 462×174, 1232×706, 748×896), Discord emoji at 128×128, Twitch emotes at 112×112, YouTube thumbnails at 1280×720 and more. Choosing one fills in both values and unlocks the aspect ratio, because platform uploads require the exact size.
  4. Or scale by percentage — Drag the slider (5–200%) or type a precise percentage. The new dimensions and scale factor update live above the preview.
  5. Download — Pick PNG, JPEG, or WebP output and hit Download. The before/after preview shows exactly what you'll get.

Does Resizing Hurt Image Quality?

Scaling down almost always looks great: pixels are blended together, so text and edges stay crisp. Enlarging beyond 100% is different — the browser has to invent pixels, which softens detail. If you must upscale, stay under roughly 150% and export as PNG to avoid adding compression artifacts on top.

Resizing Is the Cheapest Way to Shrink a Screenshot

File size scales with the number of pixels, not with the length of one side. Doubling width and height multiplies the pixel count by four; halving both cuts it to a quarter. A 3840 × 2160 capture therefore carries four times the data of the same frame at 1920 × 1080, even when both are saved with identical settings. If the destination displays your image at 1280px wide, the extra pixels are uploaded, stored and then thrown away by the platform. Resize first and the compressor has far less work to do.

The same arithmetic explains why percentage scaling surprises people. 50% sounds modest, but it leaves 25% of the original pixels. 200% sounds like double the size and is actually four times the pixels.

How the Resampler Handles Each Direction

This tool draws the image onto a canvas with high-quality smoothing enabled. When you scale down, the browser averages groups of neighbouring pixels, which is why a 4K screenshot reduced to 1080p often looks cleaner than the original — the averaging hides sensor and compression noise. When you scale up, there is no hidden detail to average; the browser has to interpolate between existing pixels. Edges soften, text loses its crispness, and sharpening afterwards only adds halos.

Downscaling is safe, moderate enlargement is tolerable, and aggressive enlargement is a different job. If you need a large print or a 4K wallpaper from a smaller source, enlarge in small steps and inspect the result at 100% between them, or start again from a higher-resolution capture. No resizer can invent texture that was never recorded.

Resize Before or After Cropping?

Crop first. Cropping changes the aspect ratio, and every platform preset assumes one. If you resize to 1280 × 720 while the capture is still 21:9, the picture is either stretched or padded; cropping to 16:9 first gives the resizer clean geometry to work with. For a batch of assets from one capture, crop once at the largest target ratio, then export each size from that master instead of cropping five times.

Common Resize Mistakes

  • Unchecking "Keep aspect ratio" without a reason. The result is a stretched HUD, not a crop. Use the crop tool when the ratio must change.
  • Upscaling past the capture resolution. Soft edges cannot be recovered by a bigger canvas; start from a sharper source.
  • Resizing a JPEG twice. Each export re-encodes it. Export once from the original and keep the intermediate as PNG if you need to continue.
  • Using percentages when a platform wants exact pixels. 50% of 2560 is 1280, but 50% of 1920 is 960. Type the target size instead of guessing.
  • Ignoring the output format. PNG keeps UI text and transparency; JPEG and WebP keep photos small. The format converter explains the trade-offs.

Frequently Asked Questions

Can I stretch an image to exact dimensions?

Yes — uncheck "Keep aspect ratio" and set width and height independently. Just know that mismatched ratios will visibly stretch or squash the picture.

Why does my upscaled image look blurry?

Upscaling can't recreate detail that was never captured. For sharp results, scale down, or keep enlargements modest (under about 150%).

Is my screenshot uploaded to a server?

No — resizing runs entirely in your browser using the Canvas API. The tool is free, needs no account, and your image never leaves your device.

Do the size presets prevent stretching?

No. Presets unlock the aspect ratio on purpose, because platforms reject anything that is not the exact size. If your artwork has a different ratio, crop it to that ratio first, then resize — otherwise it will be stretched.

Does resizing reduce file size?

Yes — fewer pixels means less data to encode. Halving width and height leaves a quarter of the pixels, which usually produces a much smaller file even at the same quality setting. For a hard upload cap, resize first and compress afterwards.

Should I resize before or after compressing?

Resize first. Compression works on whatever pixel count you give it, so shrinking the canvas before encoding saves far more bytes than lowering quality on a full-resolution file.

Can I resize larger than 200%?

The percentage control stops at 200%, but the width and height fields accept any value the browser can allocate. Enlarging beyond the capture resolution will not add real detail, so results look soft.
