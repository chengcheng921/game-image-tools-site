Base64 Encode/Decode

Convert text and images to Base64, or decode Base64 back. Local browser processing.

How to Use the Base64 Encoder/Decoder

  1. Paste your text — Type or paste any string into the left panel. Unicode is fully supported: Chinese, emoji, accents all encode correctly.
  2. Encode or decode — Click Encode → to turn text into Base64, or ← Decode to turn Base64 back into readable text.
  3. Convert an image — Use the file picker below the panels to turn any image into a Base64 data URL for embedding.
  4. Copy the result — One click puts the output on your clipboard.

What Is Base64 Encoding Actually For?

Base64 turns binary data into plain ASCII text, so it can travel through systems designed only for text. You'll meet it everywhere: data URIs that embed images directly in CSS or HTML, JSON web tokens, email attachments, basic-auth headers, and API payloads carrying files. Developers decoding a JWT will recognize the Base64URL middle section instantly. It's also handy for game modding, where some config formats store small assets as Base64 blobs. This tool handles both directions locally — sensitive tokens never leave your browser.

Base64 Is Encoding, Not Encryption

Anyone can decode Base64 — it's a transport format, not a lock. Never treat a Base64 string as a secret. If you need to protect data, use real encryption; if you just need to move it through a text-only channel, Base64 is exactly right.

Frequently Asked Questions

Why does Base64 make data bigger?

Base64 stores 3 bytes in 4 characters, so output is about 33% larger than the input. That's the price of text-only safety — keep embedded images small.

Why does decoding fail?

The input probably isn't valid Base64 — it may be truncated, contain whitespace or URL-unsafe characters (- and _ instead of + and /), or be double-encoded. Check the source and try again.

Does image-to-Base64 upload my file?

No — the image is read by your browser's FileReader and converted locally. Nothing is uploaded, and the tool is free with no signup.
