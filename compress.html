How to Use the Image Compressor

  1. Upload — Drag a game screenshot onto the drop zone or click to browse. PNG, JPG, and WebP files are supported up to 20MB.
  2. Adjust quality — Drag the quality slider (10–100, default 80) or type a precise value directly into the input field on the right.
  3. Choose output format — JPEG is best for photos and fast-loading web images. WebP gives the smallest size with near-lossless quality. PNG is ideal for screenshots with text or transparent backgrounds.
  4. Download — The compressed preview and file size update in real time. Hit Download when you're happy with the result.

What Quality Setting Should I Use?

Higher quality = larger file size. For most game screenshots shared on Discord, Steam, or social media, a quality of 70–80 with JPEG output gives an excellent balance. Use 90+ if you need maximum fidelity, or as low as 50 if file size matters more.

PNG Output Note

PNG is a lossless format — it does not throw away pixels. Our PNG compression works by reducing the color palette, which typically saves 50–80% on game screenshots. If you set quality very low and the result looks worse than expected, try JPEG or WebP instead.

PNG, JPG or WebP for a Compressed Screenshot?

All three outputs are built from the same pixels, so the choice is about what the destination accepts and how much detail you can afford to lose.

OutputCompressionTransparencyBest for
WebPLossy at the chosen qualityYesDiscord, forums and your own site, where a small file matters more than universal compatibility
JPEGLossy at the chosen qualityNoPhotoreal gameplay, email attachments and upload forms that reject WebP
PNGLossless, palette reduced to 2–256 coloursYesUI text, pixel art, logos and overlays that must stay sharp

Inside this tool the PNG quality value does not control JPEG-style compression. It sets the size of the colour palette: quality 80 keeps about 205 colours, while quality 20 keeps about 51. Flat UI art survives that well; a photograph does not, because every gradient needs hundreds of tones.

Why the File Size Barely Changed

If the numbers look disappointing, one of these is usually responsible:

  • The source is already compressed. A JPEG downloaded from Discord or Steam has been through a lossy encoder once. Re-encoding it at a similar quality cannot recover much space, and pushing lower only adds artifacts.
  • The screenshot has few colours. A clean menu screen may already sit near the smallest palette PNG can use, so palette reduction has almost nothing left to remove.
  • Pixel count dominates the file size. A 4K frame carries four times the data of a 1080p frame. No quality setting fixes that as cheaply as resizing does.
  • PNG was chosen for a photo. Photo content needs a wide palette, so a lossless PNG of a forest or an explosion can end up larger than the original JPEG.

How to Reach a Target File Size

Work through these steps in order. Each one costs less quality than the next, and the first two usually decide the outcome.

  1. Resize first. If the upload only displays at 1280px wide, halving a 2560px capture removes three quarters of the pixels before compression starts. Use the resize tool, then come back.
  2. Switch the output format. WebP is normally smaller than JPEG at the same visual quality; PNG is only competitive for flat art with transparency.
  3. Lower the quality in steps of 10. Judge at 100% zoom, not on the thumbnail. Stop at the first setting where text and edges still read cleanly.
  4. Crop dead space. Letterbox bars, repeated HUD elements and empty sky are pixels you are paying for twice.

Common caps worth designing for: 500 KB for application and support forms, 256 KB for Discord emoji, 1 MB for Steam capsule and library artwork, 2 MB for a YouTube thumbnail. If a file still misses after all four steps, the source was probably too detailed for the format, and a tighter crop is the honest answer.

What Compression Cannot Do

Compression rewrites an existing picture; it cannot add detail. Upscaling a 720p capture afterwards will still look soft, and repeatedly saving the same JPEG at 60% will keep degrading it because every pass discards more data. Renaming a file from .png to .jpg does not change its contents either — the encoder has to run, which is what this page does.

One side effect worth knowing: the browser re-encodes the image through a canvas, so EXIF camera data, GPS coordinates and PNG text chunks are not carried into the output. That is useful when you share a phone screenshot publicly, but it also means the original file remains the only copy of that metadata.

Frequently Asked Questions

Do you upload my images?

No — all compression happens locally in your browser using the Canvas API. Your image never leaves your device.

Why does WebP look different than the original?

WebP is a lossy format like JPEG. At quality 80 or above the difference is invisible to the human eye. If you need pixel-perfect output, use PNG.

Can I compress multiple images at once?

This tool currently processes one image at a time. You can open multiple browser tabs to compress several simultaneously.

Why is my PNG larger after compression?

Palette reduction works best on flat art. A photoreal frame needs a wide palette, so a lossless PNG re-encode can exceed a small original JPEG. Switch the output to WebP or JPEG for that kind of image.

Can I hit an exact target size such as 500 KB?

Not in one step — the tool shows the real encoded size, so adjust quality or dimensions and watch the number until it fits. Resizing usually moves the result further than the quality slider does.

Does compression remove metadata?

Yes. The image is redrawn on a canvas and encoded fresh, so EXIF camera data, GPS coordinates and PNG text chunks are not copied into the result. Keep the original file if you need that information.
