How to Use the Image Compressor

  1. Upload — Drag a game screenshot onto the drop zone or click to browse. PNG, JPG, and WebP files are supported up to 20MB.
  2. Adjust quality — Drag the quality slider (10–100, default 80) or type a precise value directly into the input field on the right.
  3. Choose output format — JPEG is best for photos and fast-loading web images. WebP gives the smallest size with near-lossless quality. PNG is ideal for screenshots with text or transparent backgrounds.
  4. Download — The compressed preview and file size update in real time. Hit Download when you're happy with the result.

What Quality Setting Should I Use?

Higher quality = larger file size. For most game screenshots shared on Discord, Steam, or social media, a quality of 70–80 with JPEG output gives an excellent balance. Use 90+ if you need maximum fidelity, or as low as 50 if file size matters more.

PNG Output Note

PNG is a lossless format — it does not throw away pixels. Our PNG compression works by reducing the color palette, which typically saves 50–80% on game screenshots. If you set quality very low and the result looks worse than expected, try JPEG or WebP instead.

Frequently Asked Questions

Do you upload my images?

No — all compression happens locally in your browser using the Canvas API. Your image never leaves your device.

Why does WebP look different than the original?

WebP is a lossy format like JPEG. At quality 80 or above the difference is invisible to the human eye. If you need pixel-perfect output, use PNG.

Can I compress multiple images at once?

This tool currently processes one image at a time. You can open multiple browser tabs to compress several simultaneously.
